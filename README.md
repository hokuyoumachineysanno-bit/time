# 勤怠管理 v6.2

## 同期基盤を全面再構築

- PCはGoogleポップアップ、スマホはGoogleリダイレクト認証
- ログイン後にFirestoreの `attendance-main` を必ず初回読込
- 新しいスマホでローカルデータが空の場合、クラウドを優先
- 既存端末では各勤務日の `updatedAt` を比較して統合
- Firestoreのリアルタイム監視
- 手動クラウド送信・再読込
- オンライン復旧時の自動再接続
- 同期イベントの取りこぼしを防ぐ状態再要求
- 「同期診断」ボタンで認証・データ件数・エラーを表示
- v6.2用キャッシュへ更新

## GitHubへの反映

ZIP内の全ファイルをリポジトリ直下へ上書きしてコミットしてください。

更新後：

1. PCとスマホで左上が `v6.2` になっているか確認
2. PCは同期済みになることを確認
3. スマホでGoogleログイン
4. スマホの設定画面で「クラウドから再読込」を押す
5. 問題があれば「同期診断」を押し、表示内容を確認

既存のFirestoreデータとブラウザ内データは削除しません。

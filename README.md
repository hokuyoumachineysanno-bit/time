# 勤怠管理 v8.0

## 月間俯瞰UI

- 起動時に月間台帳を表示
- スマホでも1か月を縦に俯瞰
- 日別：出勤・退勤・就労・法定時間外・法定休日労働・深夜・備考
- 日付行タップでその日の勤怠を直接編集
- 毎週（月〜日）の40時間判定を表示
- 週ごとに40h判定対象、時間外、法定休日労働を可視化
- 月度合計を固定フッター表示
- 所定休日・法定休日・会社休業日を色分け
- 法定休日変更を含む休日区分の変更履歴を保存
- 休日設定に「変更理由」を追加
- Google/FirebaseのPC・スマホ同期をv7系から維持

## 労働時間の前提
通常の1日8時間・週40時間制、週の起算日は月曜日を前提としています。
法定休日労働は法定時間外とは別枠で表示します。

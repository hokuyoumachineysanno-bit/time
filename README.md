# 勤怠管理 v8.3

## 休日・有給取得監視追加版

v8.2の36協定監視に加えて、次の監視を追加しました。

- 年間休日取得：取得済み / 年間休日目標
- 年間休日予定総数
- 今後の予定休日数
- 休日出勤によって取得できなかった休日数
- 有給取得：取得済み / 年間取得目標
- 有給残日数
- 年度末までの残日数
- 休日・有給の総合状態（順調 / 注意 / 要調整）

## 設定

- 年間休日目標
- 年度開始時の有給残日数
- 年間有給取得目標

初期値：
- 年間休日目標 110日
- 年度開始時有給残 10日
- 有給取得目標 5日

## 集計上の扱い

- 「有休」の勤務区分を1日として有給取得を集計します。
- 半日有休には未対応です。
- 有給は年間休日取得とは別枠です。
- 過去の会社休日・所定休日・法定休日で勤務実績がなければ、休日取得として集計します。
- 勤務日の「代休」は休日取得実績へ加算します。

法定の年5日有休取得義務を厳密に監視する場合は、対象者の有給付与基準期間とアプリの年度期間を一致させてください。

# 勤怠管理 Version 4 完成版

## GitHub Pagesへの反映
1. ZIPを展開します。
2. 中の全ファイルをリポジトリ直下へアップロードします。
3. 既存ファイルは上書きします。
4. GitHub Pagesを再読み込みします。
5. 古い画面なら強制再読み込み、またはホーム画面アイコンを削除して再追加します。

## Version 4の主な修正
- 出勤・退勤・外出・戻りの入力が消えないよう、入力中プレビューと保存済みデータ表示を分離
- 「今」ボタンが入力値を消す不具合を解消
- 期開始日・締め日から12月度を生成
- 過去台帳をタップして直接編集
- Excel／CSV一括取込み
- JSONバックアップ
- 初回パスワード設定、30日保持
- 既存V2/V3のlocalStorageデータを自動移行

## 注意
GitHub Pagesのパスワードは端末内の覗き見防止です。サイトそのものを非公開にする強い認証ではありません。データはGitHubではなく、使用端末のブラウザ内に保存されます。

# 勤怠管理 v5.0 台帳保存修正版

## 重要な変更
- 旧Service Workerとキャッシュを自動解除
- 各行の保存ボタンを直接イベント接続
- 保存処理を `saveRecord()` に一本化
- localStorage保存後にデータ存在を照合
- 保存後も行を再生成せず、入力内容を保持
- 表示中の変更を一括保存可能

## 更新方法
1. GitHubリポジトリ直下の全ファイルを、このZIPの内容で上書き
2. コミット後、公開ページを開く
3. 初回のみ Ctrl+F5 で強制再読込
4. 画面上部に `v5.0` と出れば新版です

既存データは v4 / v2 のlocalStorageから自動移行します。

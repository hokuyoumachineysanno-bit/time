# 勤怠管理 v6.3

## 認証復元を全面再構築

- `onAuthStateChanged`を先に登録
- その後で`getRedirectResult`を処理
- `auth.currentUser`が確定するまで待機
- リダイレクト前後を`sessionStorage`で追跡
- 認証復元に失敗した場合は診断へ明示
- iPhone Safari／Chromeのリダイレクトログイン対応
- 認証後にFirestore初回読込
- スマホのローカルが空ならクラウドを優先
- 双方向リアルタイム同期
- 同期診断に認証復元情報を追加

## 更新方法

ZIP内の全ファイルをGitHubリポジトリ直下へ上書きしてコミットしてください。

反映後：

1. PCとスマホで左上がv6.3になっていることを確認
2. スマホで「Googleで同期開始」
3. Googleアカウントを選択
4. 勤怠画面へ戻ったら10秒ほど待つ
5. 接続状態が「同期済」になるか確認
6. 問題があれば「同期診断」を押す

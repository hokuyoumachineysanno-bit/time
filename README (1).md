# 社内業務ポータル v1.1 実機テスト版

## 修正
- 日タブの「前日 / 翌日」が日本時間でも正しく日送りされるよう修正
- 月の日付クリック / タップ → その日の「日」タブへ直接移動
- 日タブ → 同じ日の「勤怠」へ移動
- 勤怠タブ → 同じ日の「予定」へ戻る
- 日送りした日付を月表示にも同期

## 労務管理と地続き
同じデータ内で以下を共通化しています。
- 社員マスタ
- 会社カレンダー（法定休日 / 所定休日）
- 日付
- 勤怠区分
- 予定 / タスク

勤怠で有休・公休などを登録すると、日フォーカスの時間バー側にも休暇情報が出ます。
日フォーカスの社員欄には、当日の勤怠入力状況 / 就労 / 時間外も表示します。

## 実機テストの位置づけ
現状の保存先は browser localStorage です。
同一端末・同一ブラウザでは保存されますが、複数端末共有はまだ行いません。
1週間程度テストし、運用が固まったら Firestore へ移行する想定です。
